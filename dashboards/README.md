# Dashboards

Dashboards Lovelace para Home Assistant.

- `dashboard_v1.3.yaml`: versión actual (Control, Energía, Diagnóstico e Ingeniería).
- `dashboard_principal_V1.2.yaml`: versión anterior, conservada como referencia.

Las entidades comienzan por `climatizacion_y_luces_midea_m_theri_ultimate_`. Sustituye ese prefijo si tu dispositivo se llama de otra forma.
